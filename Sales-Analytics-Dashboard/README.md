# 📊 Retail Sales Analytics Dashboard

## 📌 Project Overview

This project is an interactive **Retail Sales Analytics Dashboard** developed in **Microsoft Excel**. The dashboard transforms raw sales data into meaningful business insights through KPI cards, Pivot Tables, Pivot Charts, and interactive filters.

The project demonstrates the complete data analysis workflow, including data cleaning, KPI development, visualization, and dashboard design.

---

## 🎯 Business Objective

The objective of this dashboard is to help management monitor overall sales performance and identify key business trends by analyzing:

- Regional Sales Performance
- Product Category Performance
- Monthly Sales Trends
- Salesperson Performance
- Payment Method Distribution
- Quantity Sold by Category
